USB Cihaz Yöneticisi


Kısa Açıklama:
Bu proje Python ve Tkinter kullanılarak geliştirilmiş basit bir USB cihaz simülasyonudur. Kullanıcılar USB cihaz ekleyip çıkarabilir ve veriler JSON dosyasında saklanır.

Özellikler:
USB cihaz ekleme
USB cihaz çıkarma
Grafik arayüz (Tkinter)
Verileri JSON dosyasında saklama
Program kapansa bile verilerin kaybolmaması
Gereksinimler (Kütüphaneler)

Bu proje için ekstra kurulum gerekmez.

Kullanılan kütüphaneler:

json (Python ile birlikte gelir)
tkinter (Python ile birlikte gelir)


Kurulum:
Python yükleyin: https://www.python.org/downloads/
Projeyi indirin veya kopyalayın
Klasöre girin
Programı çalıştırın:

python main.py

Kullanım:
Programı aç
USB cihaz adı yaz
“USB Tak” butonuna bas
Listeden cihaz seç
“USB Çıkar” butonuna bas# Usb_Kayit_Programi
Bu proje, Python ve Tkinter kullanılarak geliştirilmiş bir USB cihaz yönetim simülasyonudur. Kullanıcıların cihaz ekleyip çıkarabildiği, verilerin JSON dosyasında kalıcı olarak saklandığı basit bir masaüstü uygulamasıdır.
